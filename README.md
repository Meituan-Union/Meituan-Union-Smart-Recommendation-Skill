# 美团生活服务智能导购 Skill

这是一个面联盟媒体场景的 Skill，核心目标是帮用户快速找到吃喝玩乐各类消费场景的美团优惠会场，精准识别用户意图并推送对应的业务会场链接，实现"说一句话，直达优惠"的短链路体验。

## 美团联盟会场简介

美团联盟会场是美团面向外部媒体和内容创作者开放的专属导购入口，覆盖外卖、闪购、餐饮团购、丽人运动休闲、医药五大业务线，以及品牌专场、品类专场等多种会场形态。媒体通过绑定专属口令，可以为自己的用户提供定制化的优惠导购服务，帮助用户以最短路径找到最合适的优惠活动。

## 核心亮点

| 亮点 | 说明 |
|------|------|
| 五大业务全覆盖 | 外卖、闪购、餐饮团购、丽人运动休闲、医药，吃喝玩乐买药一网打尽。 |
| 品牌/品类精准匹配 | 优先推送有时效的品牌专场和品类专场，无匹配时自动降级到固定兜底会场，推送始终流畅。 |
| 媒体口令绑定 | 支持媒体专属口令验证，绑定后会场数据动态拉取，链接实时更新，无需手动维护。 |

## Skill 能做什么

这个 Skill 主要提供以下能力：

- 自动识别"点外卖、买东西、去吃饭、买药、KTV、美发"等吃喝玩乐全场景意图。
- 完成媒体口令验证与用户登录，确保会场数据与媒体绑定关系准确。
- 每次对话开始时动态拉取最新会场数据，所有链接以接口返回为准，不使用硬编码。
- 按照品牌 > 品类 > 固定兜底的三层优先级，结合活动时间有效性，推送最合适的会场链接。
- 意图模糊时主动引导用户选择方向，跨业务需求时推送综合兜底会场。
- 每次对话开场时根据时间段和节日氛围生成个性化打招呼，提升用户互动体验。

## 使用方式

### 1. 触发方式

用户可以直接输入以下类型的话术触发：

- `点外卖`
- `帮我找个火锅店`
- `买点水果`
- `想去 KTV`
- `买药送到家`
- `有什么好的推荐`
- `...`（其他吃喝玩乐相关表达）

### 2. 首次使用流程

1. 首次触发时，Skill 会要求用户输入媒体口令以完成激活。
2. 用户输入口令后，调用验证接口确认口令有效性及媒体归属。
3. 口令验证通过后，自动拉取该媒体对应的最新会场数据并缓存到会话中。
4. 完成初始化后，进入打招呼流程，随后正常响应用户的导购需求。
5. 口令在有效期内后续对话无需重复验证；过期后下次对话时需重新输入新口令。

### 3. 日常使用流程

- 已完成口令绑定时，用户直接说出消费需求即可获得对应会场推送。
- Skill 会先匹配品牌专场，再匹配品类专场，均无匹配时推送固定兜底会场，全程静默降级，不打断用户体验。
- 意图跨业务模糊时（如"有什么好的"），Skill 会列出选项引导用户选择，或直接推送综合兜底会场。
- 用户说"不用了"、"算了"后，本次对话停止主动推送，等用户重新发起。

### 4. 常用场景示例

| 场景 | 示例话术 |
|------|------|
| 点外卖 | `点外卖`、`送到家`、`来杯奶茶` |
| 闪购急送 | `买水果`、`买零食`、`买鲜花`、`买美妆` |
| 餐饮团购 | `去吃火锅`、`找个餐厅`、`订座`、`团购代金券` |
| 丽人运动休闲 | `去 KTV`、`剪头发`、`健身`、`看电影` |
| 医药 | `买药`、`送药上门`、`退烧药` |
| 综合推荐 | `有什么好的`、`帮我推荐`、`今天有什么优惠` |

## 使用规则说明

- 所有对话必须先完成口令验证，未绑定媒体前不执行任何导购推送。
- 每次对话开始时必须调用接口拉取最新会场数据，不使用本地硬编码链接（接口异常时才降级使用兜底数据）。
- 闪购意图匹配时必须实际获取当前日期，不凭记忆推断，确保活动时间有效性判断准确。
- 品牌/品类专场过期时静默降级，不向用户说明"活动已结束"，保持推送流畅。
- 跨业务模糊词（如"火锅"、"烧烤"）必须先确认用户是外卖还是堂食意图，再推对应会场。

## 适用场景

适合以下使用场景：

- 媒体/内容创作者为粉丝提供美团吃喝玩乐一站式导购服务。
- 用户想快速找到外卖、闪购、餐饮团购、丽人娱乐、医药等场景的优惠会场入口。
- 用户有模糊消费需求，希望被引导到最合适的美团业务会场。
